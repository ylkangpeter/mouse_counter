# Mouse Click Recorder

一个用于统计键盘按键和鼠标点击次数的Windows桌面应用程序。icon来源：https://www.freepik.com/

## 主要功能

### 1. 实时统计
- **键盘按键统计**：实时记录键盘按键次数，只记录物理实际按压，避免按住不松手时的重复计数
- **鼠标点击统计**：分别统计鼠标左键和右键的点击次数
- **自动保存**：每10秒或每50个事件自动保存数据，确保数据不会丢失

### 2. 数据显示
- **表格视图**：显示最近30天的详细数据，包括日期、键盘按键、鼠标左键、鼠标右键的统计
- **累计统计**：显示所有历史数据的总计次数
- **图表展示**：提供折线图可视化展示数据趋势

### 3. 图表功能
- **最近一年**：显示最近365天的详细数据，按天显示
- **所有历史**：显示所有历史数据，按周显示最大值，避免数据点过多影响性能
- **交互功能**：支持缩放、滚动查看历史数据

### 4. 按键分布统计
- **详细统计**：记录每个按键的点击次数
- **排序显示**：按点击次数降序排列，方便查看最常用的按键
- **历史数据映射**：导入的历史数据会统一映射到Home键

### 5. 数据导入导出
- **导入历史数据**：支持导入`mouse_clicker.txt`格式的历史数据文件
- **数据持久化**：使用SQLite数据库存储数据，确保数据安全和完整性

### 6. 系统托盘功能
- **最小化到托盘**：程序最小化时隐藏到系统托盘
- **托盘菜单**：
  - Restore：恢复主窗口
  - View Key Distribution：查看按键分布统计
  - Import Historical Data：导入历史数据
  - Enable Startup：设置开机自启动
  - Exit：退出程序

## 数据存储

### 数据文件位置
程序会在运行目录下创建以下文件：

- **mouse_clicker.db**：SQLite数据库文件，存储所有统计数据（包括每日统计和按键分布）
- **log.txt**：程序运行日志文件

### 数据结构
程序使用SQLite数据库存储数据，包含两个主要表：

1. **click_data表**：存储每日统计数据
   - date：日期（主键）
   - keyboard_press：键盘按键次数
   - mouse_left_click：鼠标左键点击次数
   - mouse_right_click：鼠标右键点击次数

2. **key_distribution表**：存储按键分布统计
   - key_code：按键代码（主键）
   - key_name：按键名称
   - press_count：按键点击次数

## 删除历史数据

### 删除所有历史数据
如果要删除所有历史数据，请删除以下文件：

```
mouse_clicker.db
```

**重要提示**：删除`mouse_clicker.db`文件会删除所有历史统计数据，包括：
- 每日统计数据
- 按键分布统计
- 所有累计数据

删除后，程序会自动创建新的空数据库文件，重新开始统计。

### 删除日志文件
如果要删除程序运行日志，请删除以下文件：

```
log.txt
```

## 使用说明

### 首次运行
1. 运行程序后，程序会自动创建必要的数据库文件
2. 程序会自动最小化到系统托盘
3. 双击托盘图标可以恢复主窗口

### 导入历史数据
1. 右键点击系统托盘图标
2. 选择"Import Historical Data"
3. 选择要导入的`mouse_clicker.txt`文件
4. 程序会自动导入数据并刷新显示

**注意**：
- 导入时会跳过已存在的日期数据，避免重复
- 导入的键盘数据会统一映射到Home键
- 导入成功后会自动刷新表格和图表

### 查看按键分布
1. 右键点击系统托盘图标
2. 选择"View Key Distribution"
3. 弹出窗口显示所有按键的点击次数，按降序排列

### 设置开机自启动
1. 右键点击系统托盘图标
2. 选择"Enable Startup"来切换开机自启动状态
3. 菜单项前有勾选标记表示已启用

### 切换图表显示模式
在主窗口的图表区域，可以选择以下显示模式：
- **最近一年**：显示最近365天的详细数据
- **所有历史**：显示所有历史数据，按周聚合显示

## 编译和发布

### 编译项目
使用提供的编译脚本：

```powershell
.\build.ps1
```

编译脚本会：
1. 恢复项目依赖项
2. 编译项目到`bin\Release`目录
3. 复制必要的资源文件（图标、图片）
4. 创建压缩包到`release\MouseClickRecorder.zip`

### 输出文件
编译完成后会生成：
- **bin\Release\**：完整的编译输出（包括exe、dll、资源文件等）
- **release\MouseClickRecorder.zip**：打包好的压缩包

## 系统要求

- 操作系统：Windows 10或更高版本
- .NET版本：.NET 8.0 Desktop Runtime或更高版本
- 数据库：SQLite（程序内置）

## 注意事项

1. **数据安全**：定期备份`mouse_clicker.db`文件，防止数据丢失
2. **性能优化**：表格只显示最近30天数据，超过365天的数据会自动删除
3. **按键统计**：只记录物理实际按压，按住不松手不会重复计数
4. **数据持久化**：程序会自动保存数据，无需手动保存

## 技术栈

- 编程语言：C#
- 框架：.NET 8.0 Windows Forms
- 数据库：SQLite
- 图表：Windows Forms Data Visualization
